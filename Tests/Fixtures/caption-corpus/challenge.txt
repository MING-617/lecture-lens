In Python, concatenation joins strings, and casting changes a variable from a float to an integer. Computational thinking uses a data model and a user defined data type. A boolean expression controls a conditional. Mutable lists support indexing, and a formal parameter receives an argument.
In hardware, a mnemonic identifies an instruction. A subroutine uses a stack and a pointer. Ethernet sends a packet over a protocol. An interrupt handler changes the instruction register and the program counter. A hexadecimal operand can overflow a fixed length code word.
For the dissertation, traceability connects a stakeholder requirement to a deliverable. A persona guides the prototype. A literature review includes a citation and avoids plagiarism. A test harness measures accessibility, and the viva evaluates the minimum viable product.
Software engineering distinguishes aggregation and composition. Overriding and overloading differ from inheritance. A facade, a decorator and an adapter are design patterns. Scrum uses planning poker, story points and a sprint backlog. A retrospective evaluates coupling and cohesion. Kanban limits work in progress.
A database schema describes a relational model. A tuple has attributes in a domain. A superkey includes a candidate key. The primary key enforces entity integrity and the foreign key enforces referential integrity. A conceptual relationship differs from its relational representation.
Enterprise architecture can connect a mainframe and a legacy system. A stovepipe creates legacy debt. A community cloud supports resource pooling. Rapid elasticity enables cloud bursting. Shadow IT requires incident response and an audit log. Zero trust defines a service level agreement.
