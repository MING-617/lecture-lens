# Lecture Lens 0.5.3 原生辅助线程与长字幕验证

测试日期：2026-10-05。Apple M4 / Mac16,1，4 个性能核心、6 个能效核心，24 GB，macOS 26.6.2。接电充电；未调整其他应用和系统电源设置。

## 实现与测量范围

保留 Nemotron English 0.6B 560ms int8、固定源码提交 `3df7ada`、两线程、两条识别路径和 0.5 专业词权重。所有音频继续进入识别，VAD 只显示收音状态。使用方式保持直接“开始”，无需选择课程、章节或节能档位。

应用队列原来已使用 background QoS。这次通过 [ONNX Runtime 官方线程创建／回收回调](https://onnxruntime.ai/docs/performance/tune-performance/threading.html#custom-threading-callbacks)为模型的原生辅助线程也请求 background QoS。常态工作项仍为 background；待处理音频达到 0.5 秒时，将新工作项提高到 utility 以追赶。积压上限从 1 秒调整为 1.5 秒，吸收短暂调度中断，超限时仍停止并保留已收到的字幕。

1.5 秒是音频队列容量，不能代替实际词延迟或保证时限。超时原样记录；具体核心分配由 macOS 决定。原生改动与已有 1.6 秒修订补丁一起固定校验和，不跟随上游最新版。旧两行 CPU 配置仍受支持，缺失／损坏的可选配置安全回退普通 CPU 设置。

对照串行使用同一候选可执行文件、模型、词表和新队列恢复逻辑，仅辅助线程配置不同。语音按新／原／新／原顺序，另三种条件各成对。完整输入、无运行错误、字幕一致且无超过 3 秒延迟的整组比较才计算节能比例。计数从模型就绪到最终回调和释放，未包含模型启动加载。

CPU 能量沿用 [0.5.2 的系统计数方法](VALIDATION-0.5.2.md)，是系统归因的 CPU 能量，不包含完整的屏幕、DRAM、系统音频或电池功耗。CPU 时间／百分比可能因能效核心较慢而上升；接电测试不能换算整机电池续航改善比例。

## 长字幕一致性与开销

字幕只重建改动的末尾，延迟 tracker 就地替换末尾，缓存固定分词正则。AppModel 内部 tracker 不再重复发布和复制整段历史，字幕及延迟字段继续刷新界面。

1,200 次独立完整重建的差分测试覆盖增删词、回退、标点、时间戳、末行最终状态、300 行限额、旧事件、清空和会话切换。另回放 464、1,083、94 个实际识别事件，对每次完整字幕状态、所有延迟统计和保留样本顺序逐一核对，新旧一致；旧报告仍可读取。

压力微测试保留 57,600 词，重复 1,200 次末尾修订。每次字幕／延迟处理从约 0.7867 ms 降至 0.0063 ms。该加速只属于结果处理，未计模型、绘制或耗电，不代表整款软件同等比例省电。词数按每秒 2 词近似八小时历史规模，**不是实际八小时测试**；合成事件中的延迟仅用于一致性检查。

## 本次实际两小时连续检查

同一转换、连续解码、VAD、主队列回调、字幕历史、延迟统计、术语匹配和写入路径，自写合成音频按原速连续重复，模型不重置。实际经过 7206.010 秒，其中输入 7,200 秒，识别 16,731 词。画面最多保留 300 行，全文保存在文件。

最大首次字幕 1.495 秒、最终修订 2.421 秒、全程最大 2.421 秒，超过 3 秒 0 次。最大排队 0.767 秒，处理 0.761 秒，无运行错误。最终修订词序列、自动保存全文与导出内容完全一致。

首分钟物理内存占用 1383.7 MB、最后连续运行检查点 1435.0 MB；释放和导出后 58.8 MB，全程峰值 1700.7 MB。每分钟检查点保留在数值记录中，不以单次 RSS 证明不存在泄漏。

这是生产路径的文件输入测试，未包含实际麦克风、扬声器声学真值或 SwiftUI 两小时绘制。延迟基于原生词结束时间估计，误词与遗漏另计，不能用先出现的错误词掩盖正确拼写延迟。未实际运行八小时，也未测整机电池放电或此次真实教室／老师口音。

## 失败尝试与回归检查

第一次两小时验证在约 19 分钟后因合盖睡眠中断，未计为通过。测试工具现遇到系统睡眠／唤醒或运行错误就停止输入并保存中断报告，避免以部分录入冒充完整验证。人工注入 15 秒中断检查及正常 30 秒检查均确认末次字幕、保存和导出一致；中断正确返回失败。上节仅列重新执行、未中断的本次两小时结果。

最初固定低优先级辅助线程、1 秒积压上限的对照，在 FileProvider／cloud 高负载时失败；默认辅助线程也失败，最高延迟 27.647 秒。utility 辅助线程噪声能耗反而增加约 8.03%，未采用。

第一次自适应比较中，两次 background 均成功，一个默认辅助线程对照因积压中断，有 39 词错误、最高真实词片延迟 **17.936 秒**。该比较无效，不使用部分输入的低能耗当作改善。临时构建与报告移出 Documents 同步目录，负载回落后整套重新验证；未关闭或调整其他应用。失败数值与成功结果一起保留。

断言启用的回归通过，覆盖停止确认、同步关闭输入、完整保存导出、旧回调、设备中断、损坏词表／配置降级、旧报告，以及原生初始化后的取消和线程释放。新检查实际暂停音频工作 1.1 秒，同时按原速送入 1.2 秒输入，全部音频恢复处理且无积压错误；20 秒突发输入仍只报告一次错误，取消后排空。

完整数值见 [结构化结果](energy-results-0.5.3.json)。原始文字、音频、逐词事件及课堂文件不上传。
