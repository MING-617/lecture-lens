# Lecture Lens 0.5.0 验证记录

测试设备为 Apple Silicon Mac，macOS 26。测试日期：2026-10-03。候选版本为 0.5.0 / build 8；对照为已安装的 0.4.0 / build 7。以下结果区分模拟时序、真实节奏输入、实际麦克风和界面测试。

## 识别运行库与参数

- 使用原 Nemotron English 0.6B 560ms int8 模型，模型文件未替换。
- sherpa-onnx 固定为 [提交 3df7ada](https://github.com/k2-fsa/sherpa-onnx/commit/3df7adacc0d5f140e4e81b746dac0fbeeac16fab)，增加 `bounded-revisions.patch`，连续识别不重置模型状态。
- 补丁约束超过 1.6 秒的历史词片改写。它会保留部分早期误听，是防止历史内容很久后反复改写的取舍；不会截断延迟读数。
- 321 个课程词条及用户的合法英文词条进入原生 BPE 热词识别。关闭中文提示、标记已掌握与热词识别独立。
- 固定参数比较：两／四条路径 × 权重 0.5／1.0／1.5。六组在 141 词调参集均为零错误，没有超过 3 秒的修正。最终选择两条路径、权重 0.5，减少运算及增强力度；不代表对所有老师的声音都是最优参数。
- 从空的任务缓存重新构建固定源码和补丁，成功加载重建的运行库并验证识别。构建固定 CMake 3.31.6、ONNX Runtime 1.28.2；源码、补丁、模型及词典有校验，构建位置不同的二进制哈希另存收据。

延迟分开记录首次出现，以及最后一次改成最终正确拼写的时间。遗漏或仍错误的词计入错误数，不冒充有延迟样本；延迟参考模型词片结束时间，尚未逐词标注声学真值及测量屏幕绘制。

噪声和长停顿的真实节奏数值见 [生产路径结果](vocabulary-paced-conditions.json)。独立统计另有撤回后同词重现的断言，确保不沿用已撤回的较早出现时间。

## 两小时连续测试、麦克风与交付

真实 AVAudioEngine 收音测试通过扬声器播放自写英语，使用内置麦克风和原生增强识别：

- 实际收到英语字幕，测得最大延迟 0.781 秒，超过 3 秒数为 0。
- 对运行中的真实输入引擎注入 `AVAudioEngineConfigurationChange` 通知，正确停止输入、保存已收到的英语及中断原因；随后继续播放 5 秒，文件不再变化。这是实际引擎的故障注入，没有验证实体外接麦克风拔线。
- 重新开始、请求停止后取消，输入仍运行；确认停止同步移除音频 tap、关闭引擎。继续播放 7 秒，字幕和文件均不变化。
- 测试使用独立偏好与字幕目录，没有修改用户词表。

另以签名候选程序实际点击“开始”，由内置麦克风接收扬声器英语：专业词增强默认启用，悬浮与主界面持续更新同一文件。回车取消停止后仍更新；确认停止后继续播放 8 秒，字幕文件保持不变。界面累计最大延迟 1.86 秒，超过 3 秒数为 0；通过原生“导出字幕”按钮另存，文件与自动保存逐字节一致。实际收音中仍有误听，不把单次演示当成课堂准确率证明。

复查时补上计时循环在撤回较短句子时的范围保护。该一行边界修复不改变未回退输入的处理；原生解码、音频转换、窗口和保存代码未变。修复后的全部回归检查通过，最终签名程序的 141 词真实节奏输入为零错误，最大正确拼写延迟 0.780 秒。

最终签名程序再次实际收音，悬浮及主界面正常显示课程英语和中文术语；专业词增强已启用，累计最大延迟 0.80 秒、超过 3 秒数为 0。Mac 睡眠／音频设备配置改变时，程序自动停止并保留文件，恢复后可重新开始。

先前的连续测试在约 95 分钟后遇到执行暂停，期间 Mac 已锁定，恢复时最大读数为 **1,501.163 秒**，一次超时及音频积压错误；因此判定失败。无法仅凭这些记录确定具体暂停原因。失败数据保留，未删除或截断这个数值。文件输入探针不会像用户界面那样通过系统睡眠通知停止，此次恢复后的追赶不能作为正常课堂性能。

最终计时代码的完整两小时真实节奏验证已通过，进程正常退出：持续 7,201.861 秒，同一识别流不重置模型，完整保存 16,731 个词；首次字幕最大延迟 **1.191 秒**，修订最大延迟 **2.205 秒**，超过 3 秒数为 **0**，没有积压或识别错误事件。最近 10,000 个样本的 P95 为 0.852 秒，队列等待最大 0.645 秒、单次处理最大 0.628 秒。这里的错误事件指运行故障，不能解释为没有误听。

独立读取最终报告和文件后，确认所有最终词（包含修改和删除）与自动保存正文一致，导出与原文件逐字节一致，共 119,250 字节；屏幕仍只有最近 300 行。按已知音频周期及模型估计开始时间分组，118 个完整周期的 16,638 个参考词中有 23 次替换、26 次漏词和 8 次额外词，词错误率 0.343%；最后未完整周期只从准确率分析排除，仍完整保存。这个重复合成语音试验不代表课堂准确率。

`caffeinate -i` 仅在测试进程存活期间防止系统空闲睡眠，测试结束后已退出，没有改变系统永久设置。同步记录 resident memory 和含压缩／换出页的 physical footprint：运行一分钟约 1,422.8 MB，两小时约 1,464.7 MB，增长约 2.94%；加载时峰值约 1,825.2 MB。停止并释放解码器后 footprint 降到 59.3 MB。没有把驻留内存下降误当作总占用下降，也不把两小时结果当成八小时或零泄漏证明。完整数字及每分钟检查点见 [连续测试结果](continuous-results-0.5.json)。

已在上述验收后安装 **0.5.0 / build 8** 到 `/Applications/Lecture Lens.app`，严格校验签名，并逐文件确认与最终候选包相同；0.4.0 的独立 ZIP 备份保留。安装位置再次启动实际内置麦克风，无需新的权限弹窗：原生增强启用，悬浮切换和回车取消停止通过，首次出现最大 0.78 秒、修订最大 0.75 秒、超过 3 秒数为 0。确认停止后继续播放 8 秒英语，字幕文件逐字节不变。源码与验证记录使用版本标签 `v0.5.0`；不把模型、录音、课堂字幕或本机偏好提交到仓库。

## 实际限制

词表不涵盖所有未来课件；相似词仍可能误识别。以上音频不代表真实教室后排的扩音器、混响和老师口音。目标是持续跟上并控制在 3 秒以内，不能保证每个词准确或每个场景都满足延迟。没有做八小时真人课堂验收。
